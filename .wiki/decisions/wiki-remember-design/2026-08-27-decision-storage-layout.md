# Decision storage layout: flat log vs per-page grouping

Early in designing the interactive wiki-capture feature (wiki-remember), two storage
layouts were considered for conversation-derived decisions: a single flat
`.wiki/decisions.md` log, or one decisions file grouped per existing structural topic
page.
